# Ocho Años

An interactive WebGPU experience about the 8 years it takes to make one shot of tequila.
Built with Three.js (WebGPURenderer), TSL shaders, Rapier physics and my own Blender model.

## Live demo
https://webgpu-gules.vercel.app/


## Original shader
